# Unsere Spielebox

Kleine Webseite für unsere Familienspiele: Regeln nachschlagen, Punkte zählen und eine Statistik führen.
Enthalten sind Yasif, Schwimmen, Shithead und Würfeln (10.000).

- Alles steckt in `index.html`. Es gibt keine Anmeldung und keinen Server.
- Spieler, Spielstände und Statistik werden nur im Browser des jeweiligen Geräts gespeichert.
- Die Seite läuft über GitHub Pages. Zum Aktualisieren wird `index.html` ersetzt.
